## How to Use This Library

1. **Browse:** Open any `.md` file → ranked prompts with full text + source + license + use-case notes
2. **Deploy:** Copy a prompt → adapt to Jarvis context → save as `.claude/agents/{new-agent}.md` (add Jarvis safety rules + memory file references)
3. **Add new:** Run `/prompt-library {profession}` — prompt-curator-agent will research and save a new file

## Curation Discipline

Every prompt in this library has:
- **Verbatim text** quoted from source (or explicitly noted when reconstructed/composite)
- **Source URL** for verification
- **License** stated honestly (Unknown when uncertain)
- **"Why it works"** annotation
- **"Best for"** annotation
- **"Limitations"** annotation

Sensitive professions (legal, financial, medical-adjacent, mental health, parenting, relationship) require:
- Top-level disclaimer
- Refusal patterns for out-of-scope queries
- Crisis-escalation block where applicable (India-first numbers)

## Methodological Diversity

Coverage across techniques (post Wave 2 deepening):
- **Zero-shot role-play** — terse role priming, e.g., "You are a..."
- **Structured-output prompts** — XML rubrics, JSON schemas
- **Chain-of-thought / Socratic** — step-by-step reasoning, never-give-answer patterns
- **Few-shot** — embedded examples
- **Multi-phase / agentic** — research → synthesize → review chains
- **Framework-based** — STAR, RICE, JTBD, MEDDPICC, BANT, Diátaxis, etc.
- **Safety-wrapped** — disclaimer + refusal + escalation patterns

## License Note

For commercial / customer-facing deployment, prefer CC0 / MIT / Apache 2.0 prompts. The leaked-prompt section is for **inspiration when building your own** — using leaked v0/Cursor/Devin prompts as a base is industry-standard practice (Vercel's CTO publicly endorsed studying v0's prompt). Redistributing them as-is in a commercial product is not.

## Quality Bar

- **3-7 prompts per profession** — top picks only, no padding
- **Verbatim text** wherever source allowed
- **Annotated** — every prompt earns its place
- **Diverse approaches** — zero-shot, few-shot, structured, framework-based, safety-wrapped
- **Honest about gaps** — composites/reconstructions explicitly labeled
