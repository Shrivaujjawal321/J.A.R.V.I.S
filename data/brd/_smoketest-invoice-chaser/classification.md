# Classification

- **Business type:** B2B SaaS (micro-SMB / solo-operator segment)
- **Secondary characteristics:** payments-adjacent (invoice + payment status), services/booking-adjacent (client relationship)
- **Compliance surface (candidates only):**
  - DPDP Act 2023 — collecting client personal data (names, emails, possibly phone) of Indian residents
  - GST e-invoicing — ONLY if users cross Rs 5cr turnover and issue B2B invoices; unlikely for solo freelancers but must be asked
  - GDPR — only if EU-based users or EU clients
  - PCI-DSS — only if the tool ever touches card data; likely avoidable via hosted gateway
- **Initiative size budget:** Small (5-10 pages)
- **Solution stated without problem?** YES — "tool jo chase kare" is a solution noun with no stated
  problem. Five Whys ladder is a MANDATORY blocking question.
