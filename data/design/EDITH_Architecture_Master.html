4 Design Decisions — "Ye kyun, wo kyun nahi"

✅ Custom deterministic DAG  ❌ LangGraph

Prototype banaya, phir reject: single machine + must-not-crash demo ke liye fixed chain zyada reliable — no dynamic routing surprises, no framework debugging. Flow deterministic = har run same order = auditable.

✅ LightGBM  ❌ LSTM autoencoder

Evaluate kiya — LSTM ko zyada data + GPU chahiye. Tabular lag/rolling features + GBM = same accuracy, CPU pe fast. "Right tool, not fancy tool."

✅ Fine-tuned 3B SLM  ❌ bada API LLM

Plant data confidential — on-prem SLM se data bahar nahi jaata. QLoRA se free Colab GPU pe train hua. Sasta + private + fast.

✅ NLI gate  ❌ "LLM pe bharosa"

Maintenance advice galat = unsafe. Alag DeBERTa model har claim source se check karta hai — LLM khud ko check nahi kar sakta. Trust by architecture, not by hope.

✅ Template synthesis  ❌ free-form generation

Final answer ek fixed template se banta hai, numbered facts bhar ke — consistent, auditable, hallucination ki jagah hi nahi.

✅ Synthetic data (research-based)  ❌ random fake data

Pehle research — kaunsi machines, kahan sensors, real failure modes. Us par based realistic data. Design OPC-UA swap-ready = production path clear.
