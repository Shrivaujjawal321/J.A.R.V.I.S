4 Design Decisions — "Ye kyun, wo kyun nahi"

✅ Claude Agent SDK + asyncio  ❌ LangChain

Zaroorat thi: daemon + parallel fan-out. asyncio.gather ye cleanly karta hai. Framework = extra abstraction jo debug karni padti. Deterministic, inspectable control flow.

✅ ChromaDB local  ❌ cloud vector DB

Personal data local rahe (privacy), free, no network dependency. Plant analogy: on-prem for confidential data.

✅ Files + vector DB dono  ❌ sirf vector

Pakki facts (naam, preferences) deterministic chahiye — similarity search pe chhodna risky. Episodic recall ke liye vector best. Dono ka kaam alag.

✅ Haiku critic  ❌ Opus critic

Critic har reply pe chalta hai — speed + cost matter. Chhota model 4-rubric check ke liye kaafi.

✅ OAuth token  ❌ API key

Max subscription ka token = zero per-token billing. Personal system sustainable ho gaya.

✅ systemd timers  ❌ apna scheduler

OS-native, battle-tested, Persistent=true (laptop band tha to jaagte hi run). Apna scheduler likhna = reinventing the wheel.
