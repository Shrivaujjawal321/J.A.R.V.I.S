## What Wins (pattern from MumbaiHacks 2025, Google GenAI Exchange 2025, IndiaAI Impact 2025)
1. Narrow problem + deep solution (CardioSense AI did one disease very well)
2. Quantified impact in pitch (impact model is REQUIRED — don't skip)
3. Multi-modal input + accessible output (voice, image, vernacular)
4. Real Indian DPI integration signals (DIKSHA, PM-KISAN, ABDM, ONDC, Bhashini)
5. Genuinely agentic (LangGraph multi-agent > single-LLM apps)
6. 90-second demo: before-state → magic moment → after-state with impact number

## Pitfalls to Avoid
- Building dashboard when judges want an agent that *acts*
- Missing impact model (auto-loses points)
- English-only for rural use cases
- Generic "ChatGPT for X" with no twist
- Submission missing GitHub / video / architecture doc / impact model
