## Quick Reproducibility (2 steps)

### Step 1: Run the V44 ensemble to produce the K=200 base submission

Prerequisites: run the four paradigm training scripts first (in any order).
Each saves a `test_proba_*.parquet` file that `consensus_v44.py` reads.

```bash
# Install dependencies
pip install -r requirements.txt

# Train the 5 paradigms
python code/train_v35.py   # ~10-20 min, produces build_v35/test_proba_v35.parquet
python code/train_v39.py   # ~5 min,  produces build_v39/test_proba_v39.parquet
python code/train_v40.py   # ~5 min,  produces build_v40/test_proba_v40.parquet
python code/train_v43.py   # ~5 min,  produces build_v43/test_proba_v43.parquet

# Produce K=200 base submission
python code/consensus_v44.py
# Output: consensus_v44/submission_K200.csv  (72.83 LB baseline)
```

Note: `train_v35.py`, `train_v39.py`, `train_v40.py` all require:
- `data set of tata steel/dataset/train.csv`
- `data set of tata steel/dataset/test.csv`
- `build_v4/train_v4.parquet` and `build_v4/test_v4.parquet` (V4 pre-computed features)

Raw data (train.csv, test.csv) is not redistributable (Tata Steel proprietary).
`build_v4/*.parquet` must be generated by the V4 build pipeline.

### Step 2: Apply the 38 confirmed TPs to reproduce 87.17

```bash
python code/reproduce_banked.py \
    --base data/submission_K200_v44.csv \
    --tps  data/confirmed_tps.csv \
    --out  data/BANKED_K238_8717LB.csv
```

This reads the K=200 base (already in `data/`) and adds the 38 LB-probe-confirmed
True Positive CoilIDs from `confirmed_tps.csv`.

Expected output:
- `data/BANKED_K238_8717LB.csv`: 339 rows, 238 positives
- Verification PASS on all checks: row count, positive count, TP presence, FP absence

The file `data/BANKED_K238_8717LB.csv` is also pre-computed and included in this bundle.

## Score Formula

HackerEarth scores this challenge as:
```
Score = (Recall + Precision) / 2 * 100
```

Where Recall = TP / (TP + FN) and Precision = TP / (TP + FP).

This is equivalent to (the harmonic mean of recall and precision) * 100
when all positives in the test set are known.
